KESTREL — Solution Flowchart

How one frame becomes an alert a drone can be dispatched to. The spine is a cost cascade: each tier only runs when the tier before it earns the spend, because the free inference tier allows about 40 requests a minute and an eight-hour patrol produces roughly 57,600 frames.

Tier 2
Project to the world, embed for memory
Pixel → ground plane → named zone, using telemetry. This is what makes an alert dispatchable.
homography from altitude + gimbal + heading box bottom-centre = ground contact point confidence degrades with obliquity, range, GPS quality joint image/text embeddings (2048-d) for re-ID and search
Tier 3
Structured scene graph
Not a caption — objects with colour, type and activity, plus lighting and anomalies. A caption is unqueryable.
llama-3.2-11b-vision ~1.3 s detector context injected into the prompt to anchor counts validate → repair once → degrade to caption-only, never drop
Fork · escalate?
What kind of doubt is this?
need to SEE better → 90B vision, 57-84 s, ASYNC (upgrades the record after the fact) need to THINK better → reasoning LLM over the scene graph + memory, ~230 ms, on the path most escalations are cognitive, so the common case stays fast
Memory
Resolve identity, then judge
Order matters: entity first, because dwell is a property of an entity; baseline last, or the frame becomes part of the normal it is measured against.
entity re-ID appearance + attributes + spatio-temporal memory pyramid L0 frame → L1 clip → L2 event → L3 shift → L4 day baseline counts per (zone, hour, class), z-scored abstains below 3 days of history
Fork · rules
Temporal rule evaluation
Declarative data, not code — so a language model can author them and the engine can backtest them.
dwell · sequence (A then B within T) · count in window zone entry/exit · time-of-day · absence · baseline anomaly zone changes debounced: nested zones and failed projections would otherwise reset every dwell clock
Fork · triage
Does a human need to see this?
Suppression is a safety feature. Forty alerts a night trains an operator to dismiss all of them.
duplicate? suppress CONTRADICTING evidence suppress outright (a dog is not a person — scaling a confidence cannot express "this premise is false") MITIGATING evidence scale confidence, let the threshold decide (rain, PPE — but PPE never excuses a critical-zone breach) below threshold? suppress
Output
Alert you can fly to + mission proposal
Coordinates, accuracy, bearing, ETA, altitude, geofence — plus a flight plan checked against battery reserve, wind and daylight.
TARGET 18.760018, 73.862886 +/-4.9 m (geo-projection) DISPATCH 230 m from dock, bearing 47 deg, ETA 39 s FLY AT 18 m, geofence OK LAUNCH → GOTO → ORBIT(r=20m) → TRACK(ENT-0a15-0001) → RTD
Fork · the gate that matters
Human approval
KESTREL cannot fly this. Proposal and approval are separate code paths, enforced in the tool registry — prompt wording is not a security control.
declined → recorded in the ledger, nothing changes approved → mission executes, decision hash-chained
↺ The loop closes. The approved flight produces a closer, better-lit frame of the same subject. That frame re-enters at Tier 0, and the resulting change in confidence is measured against the mission rather than assumed.

Notes
Context
The organising constraint is cost, not accuracy. 40 req/min free tier 57,600 frames per 8h shift => captioning every frame would take 24 hours and cost more than the guard it replaces. Almost every frame shows the same empty yard. The architecture exists to find the ones that do not.
Edges
Handled explicitly: · projection fails (ray above horizon) → no fabricated coordinate · zone flicker at nested boundaries → debounce, or dwell never accrues · VLM returns "none" as an anomaly → nullish values filtered · provider 429 / cold start → retry + jitter, circuit breaker, cross-provider failover · no API key at all → cassette replay, byte-identical
Open
Stated rather than hidden: · telemetry is simulated — no aircraft · flat-ground projection; a raised dock would project long · re-ID uses general embeddings, not a model trained for re-identification · open-vocab detection routes through the VLM (the HF Hub was blocked on the build network) · one site has real footage; the rest of the fleet is seeded and labelled
